# cse-minor

Teaching modules for **Web Application Development (MNCST509)** — B.Tech CSE Minor, Semester 5, APJ Abdul Kalam Technological University (KTU).

Each module has simple explanations, analogies, runnable code examples, real-world examples, common mistakes, "check your understanding" questions, a mini-project, and a KTU-style question bank with model answers.

| Module | Topic | File | Hours |
|---|---|---|---|
| 1 | Introduction to HTML and CSS | [module-1-html-css.md](module-1-html-css.md) | 11 |
| 2 | JavaScript and jQuery | [module-2-javascript-jquery.md](module-2-javascript-jquery.md) | 11 |
| 3 | Server-Side Development with Node.js | [module-3-nodejs-express.md](module-3-nodejs-express.md) | 11 |
| 4 | Full Stack Integration using React and Deployment | [module-4-react-fullstack-deployment.md](module-4-react-fullstack-deployment.md) | 11 |

## Course outcomes

| CO | Outcome | Level |
|---|---|---|
| CO1 | Explain the basic structure and features of HTML5 and CSS | K2 (Understand) |
| CO2 | Describe the role of JavaScript and jQuery in creating interactive web pages | K2 (Understand) |
| CO3 | Build responsive web pages using HTML, CSS, and JavaScript | K3 (Apply) |
| CO4 | Design a full-stack web application using React, Node.js and MongoDB | K3 (Apply) |

## Assessment

- **Continuous Internal Evaluation (40 marks):** Attendance 5, Assignment/Microproject 15, Internal Exam 1 — 10, Internal Exam 2 — 10.
- **End Semester Exam (60 marks, 2.5 hours):**
  - Part A: 8 questions (2 per module) × 3 marks = 24
  - Part B: 4 questions (choose 1 of 2 per module) × 9 marks = 36
